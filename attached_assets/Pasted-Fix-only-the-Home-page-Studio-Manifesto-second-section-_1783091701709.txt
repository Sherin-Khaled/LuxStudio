# 5. GSAP ScrollTrigger Behavior

Use GSAP ScrollTrigger for this section.

Recommended structure:

```tsx
<section ref={manifestoSectionRef} className="relative min-h-screen overflow-visible">
  <div className="manifesto-inner">
    <div className="manifesto-left">...</div>
    <div className="manifesto-right">
      <div ref={point1Ref}>...</div>
      <div ref={point2Ref}>...</div>
      <div ref={point3Ref}>...</div>
    </div>
  </div>
</section>
```

Recommended ScrollTrigger setup:

```ts
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: manifestoSectionRef.current,
    start: "top top",
    end: "+=220%",
    scrub: true,
    pin: true,
    anticipatePin: 1,
  },
});

tl.fromTo(point1Ref.current, 
  { opacity: 0, y: 48, filter: "blur(8px)" },
  { opacity: 1, y: 0, filter: "blur(0px)", duration: 1 }
)
.fromTo(point2Ref.current,
  { opacity: 0, y: 48, filter: "blur(8px)" },
  { opacity: 1, y: 0, filter: "blur(0px)", duration: 1 }
)
.fromTo(point3Ref.current,
  { opacity: 0, y: 48, filter: "blur(8px)" },
  { opacity: 1, y: 0, filter: "blur(0px)", duration: 1 }
);
```

Keep the timing smooth and balanced.

Do not make the section pin too long.

Recommended scroll length:

```text
200vh–240vh
```

Do not exceed 260vh.
