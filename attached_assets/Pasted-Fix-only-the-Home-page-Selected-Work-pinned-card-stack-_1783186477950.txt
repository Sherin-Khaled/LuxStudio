## Important layout rule

All project cards must share the **same card stage / same absolute stack area**.

Do not render them in normal document flow.

Use a stack container like:

```tsx
<div className="project-stack-stage">
  <ProjectCard className="absolute ..." />
  <ProjectCard className="absolute ..." />
  <ProjectCard className="absolute ..." />
  <ProjectCard className="absolute ..." />
</div>
```

The stack container should be:

```css
position: relative;
height: enough for one card plus visible stacked edges;
overflow: visible;
```

Each card inside should be:

```css

left: 0;
right: 0;
top: 0;
```

Do **not** let project cards take vertical space one after another.

Do **not** use flex-column for the cards.

Do **not** use grid rows for the cards.

## GSAP / state logic suggestion

Use an active index based on scroll progress.

For each card, compute its relative index:

```ts
relativeIndex = cardIndex - activeIndex
```

Then apply:

### relativeIndex === 0

Active full card.

### relativeIndex > 0

Cards behind active card, stacked downward.

### relativeIndex < 0

Previous cards moved out / hidden / behind.

Example state logic:

```ts
if (relativeIndex === 0) {
  y = 0;
  scale = 1;
  opacity = 1;
  zIndex = 40;
  contentOpacity = 1;
```
