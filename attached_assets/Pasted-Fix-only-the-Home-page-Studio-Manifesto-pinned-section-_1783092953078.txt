# Important Technical Fix

The issue is likely caused by one of these:

* ScrollTrigger `end` is too short
* `pinSpacing: false` is being used incorrectly
* the next section is positioned too close or overlapping
* the pinned section does not reserve enough scroll distance
* the timeline completes too late compared to the pin duration

For this Studio Manifesto section, use:

```ts
pin: true
pinSpacing: true
anticipatePin: 1
scrub: true
end: "+=300%"
```

Do **not** use `pinSpacing: false` for this section.

The pinned section must reserve enough scroll space so the next section waits until the reveal timeline is complete.

---

# Correct ScrollTrigger Setup

Use GSAP ScrollTrigger like this structure:

```ts
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: manifestoSectionRef.current,
    start: "top top",
    end: "+=300%",
    scrub: 1,
    pin: true,
    pinSpacing: true,
    anticipatePin: 1,
    invalidateOnRefresh: true,
  },
});
```

The `end` must be long enough for all three points.

Recommended:

```text
end: "+=300%"
```

Acceptable range:

```text
"+=280%" to "+=340%"
```

Do not use less than `+=260%`.

# Point Reveal Timing

The timeline should reveal points in sequence.

Use this logic:

```ts
gsap.set([point1, point2, point3], {
  autoAlpha: 0,
  y: 56,
  filter: "blur(10px)",
});

const tl = gsap.timeline({
  scrollTrigger: {
    trigger: manifestoSectionRef.current,
    start: "top top",
    end: "+=300%",
    scrub: 1,
    pin: true,
    pinSpacing: true,
    anticipatePin: 1,
    invalidateOnRefresh: true,
  },
});

tl.to(point1, {
  autoAlpha: 1,
  y: 0,
  filter: "blur(0px)",
  duration: 1,
  ease: "none",
})
.to(point2, {
  autoAlpha: 1,
  y: 0,
  filter: "blur(0px)",
  duration: 1,
  ease: "none",
})
.to(point3, {
  autoAlpha: 1,
  y: 0,
  filter: "blur(0px)",
  duration: 1,
  ease: "none",
})
.to({}, { duration: 0.6 });
```

The final empty duration is intentional. It gives the user a short moment to see all three points fully visible before the section unpins.
