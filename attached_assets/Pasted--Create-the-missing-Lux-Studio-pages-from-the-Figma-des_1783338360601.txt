### 03 Create

Content shaping
Product data

Video / graphic support

Client involvement:

### 04 Design

Description:
We design the interface, visual system, responsiveness, interactions, and page experience with both users and development in mind.

What happens:
Wireframes
UI direction
High-fidelity screens
Responsive layouts
Design system
Motion direction

Client involvement:
Client reviews the design, gives feedback, and approves the visual direction before development.

---

### 05 Build & Connect

Description:
We build the frontend, connect backend logic when needed, prepare dashboards, CMS systems, APIs, authentication, product flows, and real business functionality.

What happens:
Frontend development
Backend development
CMS / dashboard
APIs
Authentication
E-commerce logic
Database structure

Client involvement:
Client tests key flows and confirms that the system behavior matches the business needs.

### 06 Optimize, Launch & Support

Description:
We test responsiveness, speed, SEO, accessibility basics, content accuracy, deployment readiness, hosting, and post-launch updates.

What happens:
Performance testing
SEO setup
Responsive QA

Hosting / deployment
Future support

Client involvement:

# Responsive Requirements

Desktop:
- match the Figma layout closely
- large cinematic spacing
- two-column hero where applicable
- premium cards and timelines

Tablet:
- reduce headline sizes
- maintain spacing
- avoid cramped text

Mobile:
- stack sections vertically
- no horizontal overflow
- nav remains usable
- glass cards fit screen width
- timelines become single-column
- floating words become subtle or hidden
- all text remains readable

# Performance Requirements

Avoid:
- heavy WebGL
- huge canvas effects
- video backgrounds
- too many particles
- excessive blur layers

Use optimized CSS, Framer Motion, and reusable components.
