# 4. Preferred ScrollTrigger Implementation

Use GSAP ScrollTrigger only for this Hero transition.

Create a wrapper like:

```tsx
<section ref={heroWrapperRef} className="relative min-h-screen overflow-hidden">
  <Hero />
</section>

<section ref={nextSectionRef} className="relative z-20">
  <CapabilitiesMarquee />
</section>
```

Better option:

Create one transition wrapper:

```tsx
<div ref={heroTransitionRef} className="relative">
  <section ref={heroRef} className="hero-section min-h-screen sticky/pinned">
    ...
  </section>

  <section ref={nextRef} className="capabilities-section">
    ...
  </section>
</div>
```

But do not create an extra blank 100vh section.

Recommended ScrollTrigger:

```ts
gsap.timeline({
  scrollTrigger: {
    trigger: heroTransitionRef.current,
    start: "top top",
    end: "+=100%",
    scrub: true,
    pin: heroRef.current,
    pinSpacing: false,
  }
})
```

Important:

Use `pinSpacing: false` or carefully manage the spacer so it does not create a huge blank black gap.

Animate:

```ts
heroContent: y -100, opacity 0.55
heroBackground: scale 1.06, y -60
scrollIndicator: opacity 0
nextSection: y 120 to 0, opacity 0 to 1
```

The next section should rise into place during the scroll.

Recommended values:

```text
Hero content y: 0 → -100px
Hero content opacity: 1 → 0.55
Hero background scale: 1 → 1.06
Hero background y: 0 → -60px
Next section y: 120px → 0
Next section opacity: 0 → 1
Scroll indicator opacity: 1 → 0
Scroll distance: 100vh to 120vh maximum
```

Do not use 200vh+ for this transition.
