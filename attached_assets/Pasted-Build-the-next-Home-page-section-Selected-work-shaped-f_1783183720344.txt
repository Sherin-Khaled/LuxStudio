# Section goal

This is the **Selected Work / Featured Projects** section.

It must feel like a **premium pinned storytelling section**.

The section should show **one large glassmorphism project card at a time**, while the **next cards are stacked underneath** and slightly visible.

When the user scrolls, the **next card comes forward above the current one**, like:

* stacked glass cards
* cinematic layered transition
* similar to turning through premium pages
* but **horizontal card transitions**, not vertical page flips

The user should feel like they are moving through a **deck of projects** one by one.

---

# Pinned behavior

This section must be **pinned**.

While pinned:

* only this section stays on screen
* each scroll progress reveals the next project card
* the current top card transitions out
* the next card rises and becomes the new top card
* the remaining cards stay underneath in a stacked layered view

The section should remain pinned **until all project cards have been shown**.

After the final card finishes its reveal, then the page can continue to the next section.

# Motion details

Suggested behavior:

* pin the whole section
* use scrub for smooth progress
* each card transition tied to scroll progress
* stacked cards should animate upward into the main position
* active card opacity = 1
* inactive below cards slightly dimmer
* slight scale difference is okay:

  * active card: scale(1)
  * cards below: scale(0.98 / 0.96) very subtly
* slight Y offset for stacked cards below

* top card fully visible
* next card below with translateY
* on scroll, next card rises into place and becomes active
