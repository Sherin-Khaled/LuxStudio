# 7. Correct GSAP ScrollTrigger Setup

Use GSAP ScrollTrigger for this section.

Important:

Use `pinSpacing: true`.

Do not use `pinSpacing: false` here.

The section must reserve enough scroll space so the next section does not appear early.

Recommended setup:

```ts
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: whatWeCreateSectionRef.current,
    start: "top top",
    end: "+=420%",
    scrub: 1,
    pin: true,
    pinSpacing: true,
    anticipatePin: 1,
    invalidateOnRefresh: true,
  },
});
```

Recommended scroll length:

```text
end: "+=420%"
```

Acceptable range:

```text
"+=380%" to "+=460%"
```

Do not use less than `+=360%`, because six cards need enough scroll time to reveal cleanly.

# 8. Suggested Timeline Logic

Set all cards hidden initially:

```ts
gsap.set(cards, {
  autoAlpha: 0,
  filter: "blur(8px)",

```

Then animate each card in sequence:

```ts

  { autoAlpha: 0, x: -96, filter: "blur(8px)" },

  { autoAlpha: 1, x: 0, filter: "blur(0px)", duration: 1, ease: "none" }

.fromTo(card5,
  { autoAlpha: 0, x: -96, filter: "blur(8px)" },
```
