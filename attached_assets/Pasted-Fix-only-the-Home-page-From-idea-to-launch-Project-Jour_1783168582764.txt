# 4. Required Pinned Scroll Behavior

This section must be pinned.

When the user reaches this section:

1. The section pins.
2. The left-side text remains fixed.
3. The right-side timeline area starts with all process points hidden or very faint.
4. On the first scroll step, Point 01 appears from bottom into its place.
5. On the next scroll step, Point 02 appears below Point 01.
6. On the next scroll step, Point 03 appears below Point 02.
7. On the next scroll step, Point 04 appears below Point 03.
8. On the next scroll step, Point 05 appears below Point 04.
9. On the next scroll step, Point 06 appears below Point 05.
10. Previous points must stay visible.
11. Previous points must not disappear.
12. After all six points are visible, keep the section pinned for a short moment.
13. Only then should the section unpin and allow the next section to appear.

# 8. GSAP ScrollTrigger Setup

Use GSAP ScrollTrigger for this section.

Important:

Use `pinSpacing: true`.

Do not use `pinSpacing: false`.

The section must reserve enough scroll distance so the next section does not appear before all six points are fully visible.

Recommended ScrollTrigger setup:

```ts id="p5lanz"
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: journeySectionRef.current,
    start: "top top",
    end: "+=440%",
    scrub: 1,
    pin: true,
    pinSpacing: true,
    anticipatePin: 1,
    invalidateOnRefresh: true,
  },
});
```

Acceptable end range:

```text id="effgtw"
+=420% to +=480%
```

Do not use less than `+=400%`, because six points need enough scroll distance.

# 9. Suggested Timeline Animation Logic

Set all points hidden initially:

```ts id="f0156l"
gsap.set(points, {
  autoAlpha: 0,
  y: 56,
  filter: "blur(8px)",
});
```

Then reveal them one by one:

```ts id="14924b"
tl.fromTo(point1,
  { autoAlpha: 0, y: 56, filter: "blur(8px)" },
  { autoAlpha: 1, y: 0, filter: "blur(0px)", duration: 1, ease: "none" }
)
.to(point1, { opacity: 0.72, duration: 0.35, ease: "none" })

.fromTo(point2,
  { autoAlpha: 0, y: 56, filter: "blur(8px)" },

.to(point3, { opacity: 0.72, duration: 0.35, ease: "none" })

.fromTo(point4,
  { autoAlpha: 0, y: 56, filter: "blur(8px)" },
  { autoAlpha: 1, y: 0, filter: "blur(0px)", duration: 1, ease: "none" }
)
.to(point4, { opacity: 0.72, duration: 0.35, ease: "none" })

.fromTo(point5,
  { autoAlpha: 0, y: 56, filter: "blur(8px)" },
```
